# Open Runde

Open Runde is a rounded variant of the typeface [Inter](https://github.com/rsms/inter) by [Rasmus Andersson](https://github.com/rsms).
The rounded corners are generated by a Python build script that processes Inter's static font files, applying corner rounding to every glyph while preserving all of Inter's OpenType features, kerning, and language support (147 languages).

Open Runde was originally created to be used in my app Superchat as an alternative to SF Pro Rounded. The typeface was initially called Inter Soft but was renamed to not conflict with the original Inter typeface and trademark.

- Can I legally use Open Runde for my purpose? -> Most likely yes! Open Runde is free and open source. The license is the same as Inter's ([Read the license](LICENSE.txt) for details.)

## Design

Open Runde is available in 9 weights, each with roman (upright) and italic variants — 18 fonts in total. All fonts are generated from Inter's static TTF sources using a Python build pipeline (`build/generate_fonts.py`) that extracts contours, scales to 2816 UPM, applies corner rounding, and copies OpenType layout tables (GSUB, GPOS, GDEF) from the source.
